# Documentación del Sistema de Control Escolar

Esta carpeta reúne la documentación de entrega del **Sistema de Control Escolar del Instituto Horizonte**. El sistema principal está desarrollado en Laravel 12; el prototipo Angular no forma parte del alcance funcional de la entrega actual.

| [Documentación técnica](03-documentacion-tecnica.md) | Describe arquitectura, datos, seguridad y organización del código. |
| [Instalación y despliegue](04-instalacion-y-despliegue.md) | Permite instalar el proyecto desde el repositorio de forma segura. |
| [Guion de demostración](05-guion-de-demostracion.md) | Propone un recorrido breve y ordenado para la presentación de estadías. |
| [Guía de pruebas manuales](06-guia-de-pruebas-manuales.md) | Lista de verificación para recorrer el sistema y registrar incidencias. |

## Alcance de la entrega

El alcance funcional es la administración escolar: alumnos, expedientes, estructura académica, plataformas, bajas, egresos, promoción de grupos, usuarios, permisos, historiales y reportes PDF. La API y Angular se conservan como una ampliación técnica futura, pero no son un requisito para operar el sistema web Laravel.
